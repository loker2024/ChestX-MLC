# 多模型融合实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 新增 `run_ensemble.py`，对多个 checkpoint 支持概率加权和 logits 加权，并在有标签 split 上重新计算 AUC、F1 和逐类指标。

**架构：** 保留现有单模型推理 API；在 `infer.predict` 增加 study-level logits 宽表入口，在 `infer.ensemble` 提供纯 DataFrame 融合与输入校验，在 CLI 中按每个 checkpoint 的配置分别推理后对齐、融合并输出指标或 submission。

**技术栈：** Python 3.12、PyTorch、pandas、NumPy、pytest、现有 `common.metrics` 与 `infer.submission`。

实现 CLI：

```text
--checkpoint PATH [PATH ...]
--config PATH [PATH ...]        # 可选，数量必须与 checkpoint 相同
--weights W1,W2,...             # 可选，默认等权
--fusion probability|logit
--split train|valid|test
--thresholds 0.3,0.4,...        # 有标签 split 使用
--out OUTPUT_DIR
```

每个模型优先从 checkpoint 的 `config` 恢复配置；按模型配置构造 loader 和模型，检查 study ID 与 valid 标签一致；融合后调用 `per_class_report`、`macro_auc`、`macro_f1`、`macro_f1_curve` 并写出产物。
