## 2. 固定训练口径

- 初始化：`convnext_tiny.fb_in1k` 的同一 ImageNet 权重，从预训练重新开始，不使用 `--init-from` 或旧 run 的 `--resume`；核验确实加载成功，禁止退化为随机初始化。
- 数据：原始 train/valid 划分，`resplit.enabled: false`，保留患者无泄漏约束；测试集不用于调参。
- 图像：320×320、letterbox、ImageNet 归一化、hflip 关闭、brightness/contrast 均 0.15；保留现有 RandomAffine，不额外改变几何增强。
- 模型：standard 分类头、dropout 0、全量微调、`view_weighted` logits 聚合、正侧位权重 0.7/0.3。
- 损失：BCE + 训练集原始硬标签频率计算的 `pos_weight`，power 1.0；不从 Mixup 软标签重估权重。
- 优化：AdamW、LR 3e-4、head_lr null、weight_decay 0.01、warmup 2、lr_min 1e-5、batch 16 studies、AMP、grad_clip 5。
- EMA：开启，decay 0.999；`early_stop_monitor: ema_auc`，patience 2，最多 8 轮。
- 评估：主权重 `best_ema.pt`；同时保留 raw `best.pt` 和续训 `last.pt`。raw 与 EMA 分别保存自己的最优权重。
- 禁用非本组功能：a/b 的 Mixup 参数均为 0；b/c 的 DropPath 为 0；a/c 的 cosine 终点为 null（沿用总轮数）。三组显式关闭蒸馏，缓存为 null。

## 3. 实现契约与启动前任务

已接入配置校验、EMA 早停监控、DropPath、独立 cosine 终点与 Study Mixup。旧版本已有 `early_stop_metric`，因此新增 `early_stop_monitor` 默认是 null，表示沿用既有 `early_stop_metric` 语义；旧断点缺少该旧字段时按 raw_auc 恢复。三份配置显式设置 `require_pretrained: true`，加载失败直接停止。

### 3.1 配置与 EMA 早停

涉及：`src/common/config.py`、`src/train/engine.py`、`src/run_train.py`、`tests/test_config.py`、`tests/test_ema_attention.py`、`tests/test_resume.py`。

| 新字段 | 兼容默认值 | 校验与语义 |
| --- | --- | --- |
| `model.drop_path_rate` | 0.0 | 有限数，0 ≤ 值 < 1；非零仅接受本次 timm ConvNeXt-Tiny 标准头路径 |
| `train.early_stop_monitor` | null（沿用原 `early_stop_metric`） | 仅 raw_auc / ema_auc；ema_auc 要求 EMA 开启 |
| `train.cosine_end_epoch` | null | null 沿用 epochs；显式值为整数，warmup_epochs + 2 ≤ 值 ≤ epochs，且 scheduler 必须为 cosine |
| `train.mixup_alpha` | 0.0 | 有限非负数；开启时必须 > 0 |
| `train.mixup_prob` | 0.0 | 有限数，0 ≤ 值 ≤ 1；非零要求 alpha > 0、BCE、非蒸馏、标准头与 view_weighted |

- [ ] 为非法范围、非有限值、EMA 关闭、AUCM/蒸馏与 Mixup 冲突写失败测试；确认不支持的组合直接报错。
- [ ] 早停计数使用选定指标自己的历史最好值。raw/EMA checkpoint 更新互相独立；EMA AUC 严格大于历史最高才重置计数，比较须在更新最高值之前完成。有效值首次出现视为改善；NaN 不视为改善。
- [ ] 记录监控指标、当轮数值、历史最好值、stale_epochs；在 `last.pt` 保存对应计数和监控身份。旧断点缺少监控字段时按 raw_auc 解释，不重置既有 raw 早停计数；续训禁止静默切换监控依据。
- [ ] 使用合成序列 raw=[0.80,0.79,0.78]、EMA=[0.79,0.80,0.81]，patience=2，验证 raw 模式第 3 轮停止、EMA 模式继续；再用连续两轮 EMA 不改善验证停止。中途保存/恢复与不中断训练应在同一轮停止。

### 3.3 D-006-b：提前完成 cosine

涉及：`src/train/engine.py`、`tests/test_head_lr.py`。

`cosine_end_epoch` 使用从 1 开始的轮次；每轮训练真正使用的 LR 必须如下，避免 LambdaLR 的 step 索引偏一：

| epoch | 标准 8 轮 cosine（a/c） | 第 6 轮完成 cosine（b） |
| ---: | ---: | ---: |
| 1 | 0.000150000 | 0.000150000 |
| 2 | 0.000300000 | 0.000300000 |
| 3 | 0.000300000 | 0.000300000 |
| 4 | 0.000272307 | 0.000227500 |
| 5 | 0.000199807 | 0.000082500 |
| 6 | 0.000110193 | 0.000010000 |
| 7 | 0.000037693 | 0.000010000 |
| 8 | 0.000010000 | 0.000010000 |

在现有 scheduler 中使用 `end_epoch = cosine_end_epoch or epochs`，衰减分母 `max(1, end_epoch - 1 - warmup_epochs)`，progress 截断到 [0,1]；warmup 保持原实现。

- [ ] 用实际 optimizer/scheduler 连走 8 轮，验证上表，特别是第 6–8 轮不发生 LR 反弹；null 与旧调度序列一致。
- [ ] 验证 scheduler 续训后的剩余 LR 与不中断训练相同，既有 head_lr 比例仍保持。
- [ ] 若 EMA 早停导致未进入第 6 轮，结果中标注未充分观察低 LR 保持阶段，不擅自追加固定轮数对照或延长预算。

### 3.4 D-006-c：Study Mixup

新增 `src/train/study_mixup.py`、`tests/test_study_mixup.py`；修改 `src/train/engine.py`。保持 `src/data/dataset.py` 的 study batch 与 offsets 契约。

函数接口建议固定为 `mixup_studies(images, offsets, labels, views, *, alpha, probability) -> (mixed_images, mixed_labels, mixed_count)`，计数单位为实际发生混合的输出 study。

处理规则：

1. 仅训练时、前向前执行；验证/推理完全不执行。关闭时直接返回原输入，不消耗随机数，不影响旧 seed 轨迹。
2. 在当前 batch 内按每个 study 的已知视角数量签名 `(n_frontal, n_lateral)` 分组；只混相同签名、至少两项的组。包含 unknown 的 study 本轮保留原样；单图正位与单图侧位不能互混。
3. 每组随机打乱后两两配对，奇数剩余项保持原样；不进行自配对。每对以 0.3 概率触发，触发后抽取一个 `lambda ~ Beta(0.2,0.2)`。
4. 在各视角内部按原索引顺序对应图片；同一对 study 的全部图片使用同一个 lambda。互补生成 `a'=lambda*a+(1-lambda)*b`、`b'=lambda*b+(1-lambda)*a`，从原输入读取，避免原地写入污染另一侧。
5. 在 study 层同步生成 `ya'=lambda*ya+(1-lambda)*yb`、`yb'=lambda*yb+(1-lambda)*ya`。标签仍为 [B,10]，不做并集或跨类归一化；offsets、views 与图像总数保持不变。
6. 继续通过原模型和 view_weighted 聚合得到 study logits，用原 pos_weight 的 BCE 对软标签计算损失。
7. 每轮日志和 metrics.csv 记录 `mixup_mixed_studies`、`mixup_total_studies`、`mixup_fraction`。分母是实际处理的 study 数；匹配不足时实际混合率可以低于 0.3，不得把配置概率当成实际覆盖率。
8. 使用已纳入 checkpoint 恢复的随机数生成器；如引入独立 generator，必须同时保存/恢复状态。AMP 下 labels 保持合理浮点精度。

- [ ] 对两组已知张量与标签，固定 lambda=0.25、probability=1，验证双向混合值、同视角对应和标签公式。
- [ ] 覆盖单图、多图、视角顺序不同但签名相同、unknown、奇数组、空匹配、probability=0；验证输入未被原地污染，未配对样本保持不变。
- [ ] 验证一个训练 batch 的 BCE 有限且 backward 有效；eval 完全不混合；保存 RNG 后恢复能复现下一批的配对和 lambda。
