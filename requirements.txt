#
# ============ 平台差异（wheel 体积实测，2026-10）============
#   macOS arm64  PyPI   torch-2.10.0-cp312-cp312-macosx_*_arm64.whl    75.8 MiB  CPU + MPS
#   Windows x64  PyPI   torch-2.10.0-cp312-cp312-win_amd64.whl         108.5 MiB CPU only
#   Linux x64    PyPI   torch-2.10.0-cp312-cp312-manylinux_2_28_x86_64 873.3 MiB 已捆绑 CUDA 12.x
#   Windows x64  cu128  torch-2.10.0+cu128-cp312-cp312-win_amd64.whl     2.67 GiB CUDA 12.8
#   => Windows 上直接 pip install 只会拿到 CPU 版；要 GPU 必须显式换 cu128 源。
#
# ============ macOS (Apple Silicon, MPS) ============
# 已实测: Python 3.12.14 + torch 2.10.0 + torchvision 0.25.0, mps available=True（.venv 共 842 MB）
#   python3.12 -m venv .venv && source .venv/bin/activate
#   python -m pip install -r requirements.txt
#   uv 等价: uv pip install --python .venv/bin/python -r requirements.txt
#   设备选择: "mps"（本机无 CUDA）
#
# ============ Windows (x64) ============
# 注意: 以下命令为文档说明，未在 Windows 实机验证；上表中 wheel 的存在性与体积已联网核实。
#   1) 安装 Python 3.12:
#        python.org 官方安装器（务必勾选 "Add python.exe to PATH"）
#        或 winget install Python.Python.3.12
#   2) 创建并激活 venv:
#        py -3.12 -m venv .venv
#        .\.venv\Scripts\Activate.ps1        # PowerShell
#        .venv\Scripts\activate.bat          # cmd.exe
#        source .venv/Scripts/activate       # Git Bash
#      PowerShell 报「禁止运行脚本」/ UnauthorizedAccess 时执行:
#        Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
#   3) 安装依赖（CPU 版，开箱可用）:
#        python -m pip install -U pip
#        python -m pip install -r requirements.txt
#   4) 需要 GPU（CUDA 12.8，与赛题镜像同档）时，用 cu128 源覆盖 torch / torchvision:
#        python -m pip install --index-url https://download.pytorch.org/whl/cu128 torch==2.10.0 torchvision==0.25.0
#      PowerShell 续行用反引号 ` ，cmd 用 ^ ；不要把 PyPI 的 CPU wheel 与 cu128 混装。
#      cu128 index 已核实含 cp310~cp314 的 win_amd64 wheel（torch 与 torchvision 都有）。
#   5) 自检:
#        python -c "import torch;print(torch.__version__, torch.cuda.is_available())"
#        预期: CPU 版 -> 2.10.0 False ; cu128 版 -> 2.10.0+cu128 True
#   6) 设备选择: "cuda" 优先，否则 "cpu"（Windows 无 mps）
#   7) albumentations 断网告警关闭:
#        PowerShell: $env:NO_ALBUMENTATIONS_UPDATE=1     cmd: set NO_ALBUMENTATIONS_UPDATE=1
#
# ============ Linux 服务器（对齐赛题镜像）============
#   python3.12 -m venv .venv && source .venv/bin/activate
#   python -m pip install --index-url https://download.pytorch.org/whl/cu128 torch==2.10.0 torchvision==0.25.0
#   python -m pip install -r requirements.txt
#
